## 0.30.1 — 2026-10-02

### Added

- **ProfileRequestConfig accepts authIn 'body' together with tokenParamName, includeClientCredentials and validateResponse, so a provider can send the token in a POST body and check the response.**

### Changed

- **Profile endpoints must return a JSON object; any other response now throws 'Profile endpoint returned an invalid object'.**
- **providers.hubspot looks up the signed-in portal by POSTing to HubSpot's /oauth/2026-09/token/introspect with the app's client credentials, rejects inactive tokens or a missing hub_id, and strips echoed tokens from the profile. Tokens are exchanged at /oauth/2026-09/token and refresh tokens are revoked at /oauth/2026-03/token/revoke.** (`providers`, `providerOptions`, `CredentialsMap`)

## 0.30.0 — 2026-09-23
